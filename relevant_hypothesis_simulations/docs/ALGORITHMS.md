# Algorithms implemented

This repository implements the testing framework for **relevant hypotheses** for functional time series / functional data, including:

- One-sample relevant hypotheses (mean function)
- Two-sample relevant hypotheses (difference of mean functions)
- Change-point relevant hypotheses (change in mean function)
- Two-sample relevant hypotheses for covariance operators
- Change-point relevant hypotheses for covariance operators

Two self-normalization variants are provided throughout:

1. **Quadratic self-normalization** (baseline; Dette et al., 2020)  
   Uses an “L2 / quadratic” aggregation of the partial-sum-type process to form the normalizer.

2. **Adjusted-range (range-based) self-normalization** (the manuscript’s proposal)  
   Replaces the quadratic aggregation by a **range (max–min)** aggregation, leading to a different limit distribution and typically higher empirical power in the manuscript’s simulations.

In the code, these variants appear as:

- `V_n(...)`  — quadratic normalizer + statistic (returns a length-2 vector)
- `H_n(...)`  — adjusted-range normalizer + statistic (returns a length-2 vector)

The rejection rules used in the manuscript are implemented in the helper `empRejProb(...)` in `R/generalMethods.R`, which works with tables generated by the simulation scripts.

## Where the main components live

### Data generating processes (DGPs)

`R/genData.R` contains generators for the simulation DGPs used in the manuscript:

- `fIID(...)`  — i.i.d. functional observations in a basis expansion
- `fMA1(...)`, `fAR1(...)` — dependent functional time series models in coefficient space
- `BB(...)` — functional Brownian bridges (for the BB error setting)
- plus change-point variants `cCP_fIID(...)`, `cCP_fMA1(...)`, …

### Test statistics and self-normalizers

Each setting has a “methods” file in `R/`:

- `R/OSPmethods.R` — one-sample mean tests (`S_n`, `V_n`, `H_n`, simulation writer)
- `R/TSPmethods.R` — two-sample mean tests (`D_N`, `V_n`, `H_n`, simulation writer)
- `R/CPPmethods.R` — change-point mean tests (`estCP`, `V_n`, `H_n`, simulation writer)
- `R/TSPcovMethods.R` — two-sample covariance-operator tests
- `R/CPPcovMethods.R` — change-point covariance-operator tests

### Brownian-motion based critical values

`R/generalMethods.R` provides utilities for Monte‑Carlo critical values used in multiple figures:

- `BM(...)` — Brownian motion generator (functional data object)
- `W(...)` and `quant.fct(...)` — baseline (quadratic) limit statistic + quantiles
- `W_hong(...)` and `quant.fct_hong(...)` — adjusted-range limit statistic + quantiles
